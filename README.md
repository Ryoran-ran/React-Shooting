# BLUE CURRENT

## ステージエディタ

タイトル画面の「STAGE EDITOR」または `/editor` から開けます。起承転結の区間、敵の出現・移動・攻撃、画面縮小とボス登場時刻を編集し、「試遊する」で現在の内容を確認できます。敵の出現位置と矢印先・経路点は図からドラッグでき、20～80 px のマス目に吸着できます。数値欄はマス目に縛られず微調整できます。複数の敵を編隊にまとめると、配置と出現時刻をまとめて動かせます。編隊内では横一列・縦一列・左右２列・V字の整列を選び、間隔と適用前の位置を確認して一括配置できます。矢印先までの時間から速度を計算し、移動距離・到達時刻も表示します。画面縮小は独立したイベントとして複数配置でき、時間を重ねられます。試遊はスコア記録に加算されません。

「保存」はこのブラウザの下書きに保存し、ステージ選択にも反映します。別の端末へ移す場合やバックアップには JSON の「書き出し」「読み込み」を使ってください。ブラウザのデータを消すと下書きも消えるため、確定した内容は書き出して保管してください。

イルカと、青の向こうへ。画面干渉型シューティングゲームです。タイトルからステージ1・2の道中、ボス戦、クリア、記録保存まで遊べます。Phase 4の画面・演出改善も含みます。

## 起動

Node.js 22.12 以上（22 系）または 24 以上と npm を使用します。

```powershell
npm install
npm run dev
```

ブラウザで <http://127.0.0.1:5173/> を開いてください。PC のキーボードと標準配置のゲームパッドに対応しています。別アプリやタブに移動すると自動でポーズします。

| キー | 操作 |
| --- | --- |
| 矢印 / WASD | 移動（斜め移動も同じ速さ） |
| Z / Space 長押し | 連射 |
| Shift 長押し | 低速移動 + 追尾ショットに切替 |
| Esc | ポーズ / 再開 |

### コントローラー

WindowsにUSBまたはBluetoothで接続し、ゲームのページを表示してパッドのボタンを一度押し、離してください。ブラウザが認識すると、操作ガイドが `PAD` 表示に切り替わります。

| 操作 | 標準ゲームパッド（Xbox / PlayStation表記） |
| --- | --- |
| 移動 | 左スティック / 十字キー |
| ショット | 下側のフェイスボタン（A / ×）を長押し |
| 低速・追尾 | L / R（LB / RB・L1 / R1）のどちらかを長押し。B / ○・LT / L2・RT / R2でも操作可能 |
| ポーズ / 再開 | Start / Menu / Options |
| ポーズ中の再開 / リトライ画面の決定 | A / × または Start / Menu / Options |

スティックは倒した量に応じて移動し、中心付近18%のデッドゾーンで微小なズレを無視します。十字キーはスティックより優先、キーボードの移動キーはパッドの移動より優先します。攻撃と低速はキーボードと組み合わせることもできます。

切断すると自動でポーズします。接続・再接続・再開・リセット・画面から離れた後は、スティックと操作ボタンを一度離すまで入力を受け付けず、押しっぱなしによる誤動作を防ぎます。キーボードは常に使えます。

ブラウザが `standard` 配置として認識した機器を対象にしています。未対応の配置は画面下に案内し、独自配置の割当・振動は実装していません。Gamepad APIはHTTPSまたはローカル環境で使用してください。認識の仕組みは [Gamepad APIの使用方法](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API)、ボタン配置は [W3Cの標準配置](https://w3c.github.io/gamepad/#remapping) を参照しています。

タイトルの「冒険をはじめる」からステージを選択して出航します。ステージ1は最大約49秒、ステージ2は最大約55秒の固定タイムラインで、敵の出現は繰り返しません。最後の出現まで進んで敵を倒し切ると、待ち時間を置かずボスの登場演出へ進みます。ステージ1ではアオウミガメ、ステージ2では砂浜のヤドカリが約3.2秒の演出で登場します。HP50%で第2フェーズへの切替・回収演出に入り、撃破するとクリア演出とリザルトを表示します。

タイトルの「冒険をはじめる」「戦闘練習」「操作練習」は縦並びです。タイトル・ステージ選択・リザルトでは左右のインフォボードを表示せず、全幅のメニューを表示します。プレイ中は従来の左右ボードと正方形のフィールドへ戻ります。

Phase 4ではイルカの胸びれ・尾びれの泳ぎを動かし、直進・追尾ショットの光と命中エフェクトを描き分けました。被弾時は水しぶきと画面端の淡いフラッシュ、通常敵の撃破時は種類に合わせた色の破片を表示します。左右の情報画面も、ボス接近・ボス戦・被弾・クリア・ゲームオーバーに応じて色と案内を切り替え、ボスHPは登場後だけ表示します。

メニューは上下キー / WASD / スティック / 十字キーで選択、Enter / Z / Space / A・×で決定、Esc / B・○で戻ります。コントローラーのStartでも決定・ポーズ再開ができます。画面を切り替えるたびに入力を解除し、決定ボタンの長押しを次の画面へ引き継ぎません。ポーズとゲームオーバーからステージ選択へ戻れます。

タイトルから「戦闘練習」「操作練習」も選択できます。戦闘練習は従来の42秒ループです。右パネルの「敵との戦闘」を OFF にすると、操作練習へ切り替わります。モード切替時は HP・時間・弾・敵・練習設定を初期化します。練習のスコアは保存しません。ロックオンマーカーは表示しません。

戦闘練習中の「敵の攻撃」を OFF にすると敵弾とレーザーの予兆・発射を解除し、射撃なしで敵を撃つ練習ができます。**敵本体への接触判定は残ります。** 操作練習モードのクラゲには撃破・衝突判定がありません。記録対象のステージでは練習用設定を表示しません。

## ステージと記録

- ステージ1「サンライト・ラグーン」を実装。通常敵5種の道中と、2フェーズの基本ボス1体。画面干渉ギミックはありません。
- ステージ2「ひかりの浅瀬」を実装。ステージ1の上から降る編隊と異なり、敵が左右から交差・挟撃します。クラゲの自機狙い弾、ハリセンボンの扇弾、砲台の挟撃弾もステージ2専用です。道中で2回、予兆のあと背景を含む画面と移動可能な戦場が滑らかに縮み、しばらくして元に戻ります。ボス登場時には砂浜へ背景が変わり、2フェーズのヤドカリと戦います。ステージ選択から直接遊べます。
- ボスは登場中・フェーズ切替中は無敵。フェーズ終了時は敵弾とレーザーを金色の得点アイテムに変え、緑の回復アイテムも自動回収します。弾・レーザー由来は1個10点、フェーズ突破の大きな結晶は100点。約2.4秒の演出と回収の完了後に次フェーズへ進み、攻撃待ち時間を再設定します。移行中は自機も無敵です。
- ボスはレーザーの予兆開始から発射終了まで移動を止め、口元に発射口の光を表示します。射線は予兆開始時に固定し、発射中も同じ位置から撃ちます。終了後は滑らかに移動を再開します。
- ステージ1の標準難易度は入口を保ち、ボス第2フェーズの扇弾を9発・1.7秒間隔から11発・1.55秒間隔へ、弾速を150から158px/sへ調整しました。狙い弾は170から175px/sにし、レーザーの予兆1.4秒は維持しています。難易度選択はまだありません。
- ボス撃破で全弾・ほかの敵・アイテムを解除し、ゲーム時間と自機座標を止めます。ボスは光の波紋と粒の中で沈みながら薄く消え、約1.6秒後に「STAGE CLEAR」を表示します。その余韻を見せてから約4.8秒後にリザルトへ進みます。
- 毎回のステージ開始・リトライでHP10、回復ゲージ0、スコア0、敵配置と乱数シードを初期化します。
- 撃破点：小型100、突進型100、中型300、固定砲台300、大型1,000、ボス5,000。退場とイカの接触自爆は加点しません。
- クリア時：3,000点 + 残HP×1,000点 + ノーミスなら5,000点。回復でHP10に戻しても、被弾履歴があればノーミスにはなりません。
- ステージ1の仮評価：Sは24,000点以上、Aは19,000点以上、Bは14,000点以上、その他C。
- ステージ2の仮評価：Sは27,000点以上、Aは22,000点以上、Bは16,000点以上、その他C。
- `localStorage` の `blue-current.records` にバージョン1のステージ別記録を保存します。クリア済み、最高スコア、最高ランク、ノーミス、最速クリア時間、プレイ回数、クリア回数を保持します。
- プレイ回数は出航・リトライ時に加算。スコア・評価・タイムはクリア時にのみ正式記録し、失敗・途中帰還・練習では更新しません。低い点数で再クリアしても最高記録を保持します。
- 保存が無効・容量不足・データ破損でもゲームを続けられます。書き込めない場合は結果と選択画面で案内し、そのページを閉じるまでは記録をメモリで保持します。

## 実装範囲

- React・TypeScript・Vite・PixiJS による 1280×720 の画面。左右 280×720、中央 720×720。全体を等比率でリサイズ。
- 背中を上から見た水色の仮イルカ。左右の胸びれ・背びれ・尾びれを描画。尾びれの泳ぎ、移動時の傾き、低速時の穏やかな動き、発射エフェクト。
- 通常 300px/s、低速 120px/s。境界内への制限、生存中は半径 4px の判定点を常時表示。
- 直進ショット：間隔 0.12 秒、速度 600px/s、威力 2。
- 追尾ショット：間隔 0.20 秒、速度 450px/s、威力 1、旋回上限 180°/秒。正面との角度が小さい対象を優先し、同角度では近い対象を優先。
- 発射時の対象を追尾。対象消失後は最後の方向へ直進し、別対象を取り直しません。対象不在時は正面へ発射。
- 60Hz の固定タイムステップと描画補間。連射間隔はゲーム時間から計算。
- ポーズ、入力の解除、非アクティブ時の自動停止、リセット、初期化失敗時の案内。
- HUD は 10Hz で更新し、毎フレームの React 再描画を回避。
- Gamepad APIを描画フレームごとにポーリング。ポーズ中もStart・決定を検出し、接続状態や操作ガイドは状態変化時にだけReactへ通知。
- 小型（クラゲ）・中型（ハリセンボン）・固定砲台（イソギンチャク）・突進型（イカ）・大型（マンタ）の5種。見た目・性能は敵データとして分離。
- イカは自機に接触すると爆発して消滅。接触ダメージは通常どおり1で、無敵中は無傷でもイカは爆発する。接触による自爆では撃破数・ドロップを発生させず、ショットで倒した場合は通常の撃破として扱う。
- 42秒の固定パターンを繰り返す戦闘練習。出現時間・位置・種類・移動・退場時間を外部データで定義。
- 直線・波状・ジグザグ・追尾・定位置への移動と停止・指定経路の6種類の移動。
- 直進弾・発射時の自機狙い弾・予兆付きレーザー。攻撃間隔と大型敵の残HPによる追加攻撃を設定可能。
- レーザーは予兆開始時に射線を確定。予兆1.2秒中は無害で、その後0.65秒だけ接触判定が発生。
- 追尾ショットは出現済みで生存中の敵を対象にする。撃破・退場した対象は追い直さず、最後の方向へ進む。
- World座標で円形判定。前フレームからの相対移動も判定し、高速弾のすり抜けを防止。自機弾は手前の敵1体に命中して消える。
- 自機の判定半径4pxと見た目を分離。敵本体・敵弾・発射中のレーザーでHPが1減少。被弾後1.5秒は無敵になり、点滅・波紋で表示。
- 敵の撃破・被弾・回復のエフェクト、敵の残HP、自機HP・回復ゲージ・撃破数・敵弾数を表示。
- 命中時はショットの種類に応じた小さな光、被弾時は「ぱしゅん」の水しぶき、通常敵の撃破時は種類に応じた波紋・破片を表示。これらは当たり判定やスコアから独立した短命の描画効果です。
- 撃破した通常敵の弾は残存。退場は撃破に数えず、アイテムも落とさない。
- 滞在時間切れ・経路終了時は攻撃を止め、近い上端・左右端へ加速して退場。姿が完全に画面外へ出てから削除。退場中も撃破は可能。
- 回復アイテムは緑の「＋」。接触取得でゲージ+20、100でHP+1、余剰は繰越。HP最大時は蓄積せず、HP0からは回復しない。
- ドロップ率は小型15%、中型40%、固定砲台50%、突進型15%、大型100%（2個）。乱数はリトライで同じシードに戻す。
- HP0で全弾・レーザーを解除して戦闘を停止。イルカが1.2秒かけて下へ落ち、消えてからリトライ画面を表示。「リトライ」でHP10、回復ゲージ0、敵の出現順も最初から再開。落下は表示だけの演出で、内部の自機座標と経過時間は変えない。

## 動作確認

```powershell
npm test          # 純粋なゲームロジックと入力ライフサイクル
npm run build    # TypeScript 型チェック + 本番ビルド
npm run preview  # 本番ビルドをローカルで確認
npm run test:e2e # インストール済み Google Chrome でブラウザテスト
```

E2E は開発サーバーを自動起動します。Chrome がない環境ではインストール後に実行してください。スクリーンショットは `artifacts/` に保存します。

手動確認のポイント：

1. 矢印 / WASD で泳ぎ、画面端でもイルカがはみ出さないことを確認。
2. Z を押したまま Shift を押す・離す。弾の色、移動速度、ショットの直進 / 追尾が変わることを確認。
3. タイトルからステージ1を選び、約1.2秒後からクラゲが出現すること、ショットで敵が消え、撃破数・スコアが増えることを確認。
4. 赤い敵弾・敵本体に触れ、HPが1減ってしばらく点滅することを確認。無敵中にHPが連続して減らないことを確認。
5. 開始約13秒以降のイソギンチャクの予兆線を確認。細い予兆線は無害で、太く光ってから危険になることを確認。
6. 緑の「＋」アイテムを取得。HPが減った状態で5個集めると1回復し、最大HPではゲージが増えないことを確認。
7. HP0で戦闘が止まり、イルカが落下してからリトライ画面が出ることを確認。「リトライ」でHP10・ゲージ0・撃破数0・最初の敵配置に戻ることを確認。
8. Esc で敵・弾・レーザー・回復アイテム・無敵時間も止まることを確認。別ウィンドウへ移動後に入力が残らないことを確認。
9. タイトルの「戦闘練習」で「敵の攻撃」を OFF にして敵弾・レーザーが消えることを確認。「敵との戦闘」を OFF にして、従来のクラゲの表示・移動を確認。
10. 操作練習で追尾弾が飛んでいる間にターゲットを消し、直進を続けることを確認。
11. リセットとブラウザのリサイズを確認。16:9と中央の正方形、既存の画面サイズを維持。
12. Shiftを離しても判定点が見えることを確認。倒さずに残した砲台・大型敵が、時間切れで画面端へ移動して退場することを確認。
13. パッドで移動・ショット・低速・ポーズ・再開・リトライを確認。Start長押しで何度も切り替わらず、切断・再接続後に移動や射撃が残らないことを確認。
14. 道中の最後の敵を倒した直後、または最大約49秒で接近・登場演出になることを確認。HP50%で弾が金色のアイテムになって自機へ集まり、回収後に第2フェーズが始まることを確認。レーザー中はボスが停止し、口元から予告どおりの射線を撃つことも確認。
15. ボス撃破後にボスの消失、クリア表示、リザルトの順に進むことを確認。結果・ボーナス内訳・評価を表示し、ステージ選択と再読み込み後も記録が残ることを確認。リトライ・途中帰還では最高スコアが変わらないことを確認。
16. メニューをキーボードとパッドだけで往復し、決定ボタン長押しで次画面の射撃や再決定が起きないことを確認。
17. 道中ではボスHPが表示されず、接近・ボス戦・被弾・クリアで左右パネルの状態と案内が切り替わることを確認。通常移動と低速移動でイルカのひれの動きが変わり、2種類のショット・命中・撃破エフェクトを確認。
18. `npm run test:e2e -- --grep 'Phase 4 combat effects'` で戦闘中の描画間隔を測定。開発環境のChromeで敵と連射中の3.5秒は210フレーム、中央値16.7ms、95パーセンタイル17.0msでした。実機や画面サイズで変わるため、目標60FPSの参考値です。
19. ステージ選択からステージ2へ出航し、左右からの交差攻撃を確認。約14秒と32秒で縮小の予兆が出て、画面と戦場が縮み、ポーズ中は止まり、復帰後は元の広さになることを確認。ボス接近時に砂浜へ切り替わり、ヤドカリの2フェーズ、クリア演出、ステージ2専用の記録保存まで確認。

## コード構成

```text
src/
  app/                 React の画面・HUD・リサイズ・ゲームの接続
  game/
    config.ts          調整用の仮数値（秒、ワールド座標 px）
    core/              ゲーム状態、固定更新ループ、座標変換
    entities/          自機・自機弾・敵・敵弾・レーザー・アイテムのデータ
    systems/           入力、移動、出現、攻撃、衝突、回復、ステージ進行、スコア
    stages/            ステージ一覧・固定出現パターン・評価基準
    bosses/            ボスのHP・フェーズ・移動・攻撃の定義
    persistence/       バージョン付き記録の検証・読み書き
    rendering/         PixiJS による描画のみ
  data/enemies.ts      敵のHP・見た目・当たり判定・射撃・ドロップ設定
  tests/               Vitest の単体テスト
e2e/                   Chromium での操作・リサイズ確認
```

`Game` は DOM・React・PixiJS を参照しません。移動・追尾は World 座標で処理します。`state.field` が移動範囲、`state.view` が表示の拡大・回転・移動を担い、独立しています。`coordinates.ts` に相互変換関数があり、描画側が View を適用します。React の左右パネルは Pixi のシーンから分離しています。

`game/config.ts` で速度・発射間隔・旋回速度・被弾・回復等、`data/enemies.ts` で敵の性能、`game/stages/trainingGround.ts` で練習パターンと簡易ターゲットを調整できます。`game/stages/stages.ts` の `STAGES` へ定義を追加すると選択画面に反映されます。ステージごとに名称・道中とボス戦の背景・出現タイムライン・ボス・評価閾値・ギミックイベントを指定します。ボスは `game/bosses/`、得点は `game/systems/ScoreSystem.ts` に分離しています。縮小ギミックは `game/systems/GimmickSystem.ts` が World 座標を保ったまま View と Field を制御します。同時発動した縮小幅は加算、表示倍率は乗算して、最低限の遊べる範囲を保ちます。ほかのギミック種別は今後追加します。

移動・攻撃・当たり判定・ドロップは描画から独立しています。通常敵の弾とレーザーは発射元への参照を保持しないため、発射元を撃破・退場させてもそのまま残ります。敵の退場と撃破は別経路で処理します。
